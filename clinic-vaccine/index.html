FEATURES

短い時間で受けられるように、
3つの工夫をしています

01

予約は24時間、Webで

空いている日と時間帯を見て、その場で予約できます。電話がつながるのを待つ必要はありません。

→ 夜や休みの日に、思い立ったときに予約を済ませられます。

02

問診票はスマホで先に

予約のあとに届くリンクから、体調やアレルギーの有無を入力できます。当日は受付で名前を伝えるだけです。

→ 院内で書く時間がなくなり、そのぶん早く帰れます。

03

接種の方専用の時間帯

一般の診察とは時間を分けて、予防接種の方だけを案内する枠を設けています。

→ 体調の悪い方と長い時間、同じ待合室で過ごさずに済みます。

FLOW

予約から接種までの流れ

  1. Webで予約

    日と時間帯を選び、名前と電話番号を入力します。

  2. 問診票を入力

    届いたリンクから、前日までにスマホで入力します。

  3. 来院・診察

    受付で名前を伝えてください。医師が問診票を見て、体調を確認します。

  4. 接種・様子を見る

    接種のあと30分ほどは、院内か近くで様子を見てください。

次の方は、予約の前にお電話でご相談ください

  • 当日、熱がある方（その日は接種できません）
  • 以前、予防接種のあとに体調が悪くなったことがある方
  • 持病で治療中の方、妊娠中の方

どの場合も、受けられるかどうかは医師が問診で判断します。

FAQ

よくある質問

予約しないで行っても受けられますか？

ワクチンの数に限りがあるため、予約の方を優先しています。空きがあれば当日も受け付けますので、お電話でご確認ください。

家族とまとめて予約できますか？

できます。フォームの「接種する人数」を選んでください。13歳未満のお子さまがいる場合は、チェックを入れてください。

ほかのワクチンと同じ日に受けられますか？

組み合わせによっては受けられます。予約のあと、問診票の備考欄に書くか、当日医師にご相談ください。

接種した日に、お風呂に入ってもいいですか？

入って大丈夫です。接種したところを強くこすらないようにしてください。

予約の日に熱が出たら、どうすればいいですか？

その日は接種できません。届いたメッセージのリンクから、予約を取り消すか日を変えてください。
